# Buy or Wait? master roadmap

## Hackathon

1. Converge the product branch on the committed finance checkpoint without
   changing finance semantics.
2. Retain the lab as the single product shell and preserve red-team evidence.
3. Ship the proprietary observation model/store and current-offer capture path.
4. Ship deterministic price intelligence, used/refurb handling, and watches.
5. Add decision synthesis, evidence envelope, adversarial review,
   certification, committee, and final veto.
6. Run Demo A (safe + good), Demo B (safe + poor), and Demo C (great deal +
   unsafe) with clearly labelled fixtures.
7. Run imported and integration tests, red-team checks, and final release
   hygiene. Package only after the finance lane converges its newer core.

## Near-term

- connect the upgraded finance provider through `FinancialDecisionProvider`;
- wire authorized live current-price providers and grow first-party history;
- add durable encrypted tenant-scoped repositories;
- automate price watches, notifications, and scheduler refreshes;
- implement native barcode/photo/OCR/share intake with privacy controls;
- deploy the Cortex reviewer as an optional or mandatory configured gate;
- replace fixture authentication with verified production identity.

## Future

- connected bank, card, loan, and brokerage sources;
- cloud persistence and event-driven ingestion;
- large-scale authorized price collection;
- forecasting, category priors, seasonality, and replacement intelligence;
- personalized timing and human escalation;
- multi-model/process reviewer diversity and governance analytics.

The release order is deliberate: financial safety and evidence integrity remain
hard prerequisites for all price and product expansion.
