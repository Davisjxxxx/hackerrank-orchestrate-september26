# Data handling

Raw provider data is retained as immutable evidence with a payload hash and
source metadata. Canonical records are derived, never used to overwrite raw
payloads. Documents use content-addressed filenames and must be deleted through
an authenticated retention workflow. Email ingestion stores sanitized text and
metadata only when the user authorizes read-only Gmail access.

Plausible but uncertain facts remain non-authoritative and visible for review.
Pending credits, unapproved income, one-time credits, and unrealized values
never become spendable cash. User corrections create explicit evidence and do
not mutate provider history.
